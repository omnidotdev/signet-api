# Signature fonts

Handwriting faces a signer can choose for a typed signature. Each is embedded
(subset to the glyphs of the signer's name) into the signed PDF. Their licenses
permit bundling and embedding, and each license file ships beside its font as
the license requires.

| Style id     | Font           | License            | License file                |
| ------------ | -------------- | ------------------ | --------------------------- |
| `sacramento` | Sacramento     | SIL Open Font 1.1  | `Sacramento-OFL.txt`        |
| `dafoe`      | Mr Dafoe       | SIL Open Font 1.1  | `MrDafoe-OFL.txt`           |
| `homemade`   | Homemade Apple | Apache License 2.0 | `HomemadeApple-LICENSE.txt` |

Source: the Google Fonts repository (`github.com/google/fonts`). The `classic`
style uses the PDF standard Helvetica Oblique face and needs no file.
